WisePage is a collaborative writing space with an AI agent built in, where a passing thought, shared among many minds, grows page by page into something wise.

## What you can do

- **Real-time collaboration.** Your whole team writes on one live page, with every cursor and edit synced instantly.
- **Edit with the agent.** A built-in agent understands your workspace and draws on the web to write, edit and organize your pages.
- **One request, your whole workspace.** An agent with long-term memory builds on everything you've written to turn intent into finished pages.
- **Type @Agent and keep writing.** Tell the agent what to write at any spot on the page. It works in the background while you carry on.
- **Ask AI anywhere, in one click.** Select text to improve it, fix spelling and grammar, translate, explain or summarize it without leaving the page.
- **Share with a few, or publish to everyone.** Invite people to edit or view a page. When it's ready, publish it as a link anyone can open.
- **You decide what it remembers.** See every memory and the chat it came from. Filter, edit or delete any of them, or turn memory off.
